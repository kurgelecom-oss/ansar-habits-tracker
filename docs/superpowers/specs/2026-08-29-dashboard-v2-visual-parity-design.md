# Dashboard V2 Visual-Parity Design

**Reference:** `/Users/taylankursunlu/Downloads/ansar-dashboard-weekday-journal-location.png`

## Outcome

The verified Dashboard V2 keeps every real learning, Tally, Supabase, Notion,
override and wallet behaviour, but its presentation must visibly belong to the
approved ANSAR FC concept rather than read as a compressed technical refactor.

## Visual authority

- Treat the supplied image as the authority for hierarchy, atmosphere, depth,
  typography and panel finish.
- Do not copy its fictional points, gems, streaks, habits, teams or score.
- Real server data remains authoritative. Until football data is connected, the
  Match Centre must state that it is unavailable and show no invented opponent
  or result.

## Composition

1. One premium internal ANSAR FC navigation bar with a shield mark, Dashboard,
   Habits, Quests, Team, Table, History and Settings, plus real status data.
2. Hide the redundant shared cross-surface TopNav on this dashboard route only;
   do not edit or delete the shared component.
3. A stadium masthead carrying `Ansar · ANSAR FC` as the page identity.
4. A substantial Match Centre frame with Real Madrid identity and separately
   labelled Match Readiness.
5. Four premium panels: Morning Habits, Today's Programme, Work + Week and
   Stretch Wallet.

## Signature

The memorable element is the stadium tunnel: masthead and Match Centre sit on
the same dark Bernabéu atmosphere, separated by thin gold/cyan pitch lines.
Panels feel like the tactical bench below it, not generic SaaS cards.

## Typography and colour

- Display: Georgia/serif for the masthead only.
- Interface: existing system sans for controls and habit text.
- Data: tabular numerals with restrained condensed spacing.
- Palette remains the approved navy, gold, cyan, near-black, success, danger
  and wallet purple tokens. No fictional currency colour system is introduced.

## Journal and Homeschool

- Journal is the first weekday programme row.
- Journal receives a persistent gold focus edge and `Journal prerequisite`
  eyebrow so its importance is visible without pretending it awards points.
- Homeschool session receives a stronger cyan edge and five-point chip while
  remaining a 44px-or-taller row.
- `Recorded`, `Verified` and `Parent override` remain distinct terms.

## Height and responsiveness

- At exactly 1440 × 820: no page scroll, no panel scroll, no clipped/hidden
  configured habits, and habit rows remain at least 44px.
- The dashboard-only removal of the redundant 40px shared TopNav funds the
  masthead and stronger Match Centre; learning rows are not compressed.
- At tablet/mobile widths panels stack, the masthead shortens, the Match Centre
  stacks, and server clock plus connection state remain visible.

## Release boundary

- Preview branch and draft PR only.
- Protected routes, server libraries, database files and Netlify configuration
  remain byte-identical.
- Production requires side-by-side owner review against the supplied image.
